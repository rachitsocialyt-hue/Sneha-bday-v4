# THE SNEHA UNIVERSE
A cinematic birthday website for Sneha — 17 October, 20.

## Run
Open `index.html` in a modern browser. For the cleanest local experience, use VS Code Live Server.

## Included
- Universe / space cinematic visual system
- 7 scenes with mouse-wheel, touch, keyboard and dot navigation
- Continuous background piano music with play/pause control
- Original video aspect ratio preserved with WebM + MP4 fallback
- Four-photo cinematic orbit
- Interactive constellation cards
- Birthday 20 reveal + particles
- Personal letter and final message
- No external JS dependencies
